Addons

Write your own modules.

Plain Java. Loads without a restart.

How it works

  1. Drop a .java file in ~/Arsenic/addons
  2. Type .addon reload
  3. It’s in your ClickGUI
.addon new MyModule combat   # start from a template
.addon reload                # compile + load
.addon list | .addon folder

Same API as built-in modules. Compile errors print in chat; everything else still loads.

Let AI write it

Give any AI ADDONS.md and describe the module. Paste errors back until it compiles.
