Home / Install

Inject in three steps.

You need Minecraft 1.8.9 and a JDK (8, 17 or 21). It’s not a mod: keep it out of .minecraft/mods.

Vanilla or Forge

  1. Open Minecraft 1.8.9
  2. Run the Arsenic jar
  3. Pick your game, press Inject

Lunar

  1. Run the Arsenic jar
  2. Click inject into lunar. Lunar closes.
  3. Reopen Lunar on 1.8.9 with OptiFine

Your files

Configs and addons live in ~/Arsenic (C:\Users\<name>\Arsenic on Windows), shared by every launcher.

Build from source

  1. Install JDK 8 and set JAVA_HOME
  2. Clone the repo
  3. Run setup.bat or setup.command
  4. Open Arsenic.ipr in IntelliJ
  5. Run gradlew build
