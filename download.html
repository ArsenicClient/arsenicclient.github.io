Download Arsenic

Free and open source. Releases are hosted on GitHub — the button always points at the newest jar.

Prefer GitHub? Open the releases page.

Before you run it: you need a JDK, and you inject the jar into a running game — don't put it in .minecraft/mods. Follow the install guide. Only download from this site's links or the official GitHub repository.
