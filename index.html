About Arsenic Client

Arsenic is a free, open-source Minecraft 1.8.9 cheat client targeting competitive players on Hypixel. It runs as a standard Forge mod — no launcher patching, no sketchy injectors, just drop it in your mods folder.

The client's core focus is passing the prediction Anti-Cheat system used on Hypixel. Any module that triggers detection flags is immediately patched or pulled from the build, keeping your account safe.

Arsenic includes a full module system, command interface, persistent config system, and a polished ClickGUI — built on custom Mixins and a lightweight event bus for maximum performance.

To build from source: clone the repo, run setup.bat, load the Gradle project in your IDE, and start developing. Contact @kv.dev on Discord for setup help.
