About Arsenic Client

Arsenic is a free, open-source Minecraft 1.8.9 client built around the Hypixel and Prediction anti-cheats. Anything that flags is removed from the base client, and the philosophy is to keep the experience as simple as possible: few settings per module, so features just work.

As of v3.0 Arsenic is no longer a Forge mod. It is an external injector that attaches to a running Vanilla, Forge or Lunar Client game. Configs, addons and themes live in one Arsenic folder in your home directory, shared across launchers.

Want more customisation? The addon system lets you write modules as plain .java files, hot-loaded with .addon reload — or hand the ADDONS.md reference to an AI and describe what you want.

Ready to try it? Read the install guide, then download the latest jar.
