FAQ

Frequently asked questions

Everything you need to know about Arsenic Client.

What is Arsenic Client?

Arsenic is a free, open-source Minecraft 1.8.9 client built around the Hypixel and Prediction anti-cheats. Anything that flags is removed from the base client, and modules have few settings so they work without configuration. Since v3.0 it is an external injector rather than a Forge mod.

How do I install Arsenic Client?

Start Minecraft 1.8.9 (Vanilla or Forge), double-click the Arsenic jar, pick your game in the window and press Inject. For Lunar Client, double-click the jar and choose "inject into lunar", then reopen Lunar on 1.8.9 with OptiFine. Never put the jar in .minecraft/mods. You need a JDK installed.

Is Arsenic still a Forge mod?

No. Since v3.0 Arsenic is no longer a Forge mod. It is an external injector that attaches to a running Vanilla, Forge or Lunar Client game at runtime, so the jar must not be placed in the mods folder.

Is Arsenic Client free?

Yes. Arsenic is completely free and open source under the MIT License. The source is on GitHub and contributions are welcome.

Does Arsenic work on Hypixel?

Arsenic is built around Hypixel and Prediction anti-cheat, and anything that flags is removed from the base client. No cheat client can promise you will never be banned, so test new modules carefully and use at your own risk.

Which Minecraft version and launchers does Arsenic support?

Minecraft 1.8.9 only. It injects into Vanilla, Forge and Lunar Client (Lunar with OptiFine on 1.8.9).

What are addons and packs?

Addons are plain .java module files you drop in ~/Arsenic/addons/. They are compiled when the client starts or when you run .addon reload in chat. Packs are bundles of addons such as the Bedwars and Pit packs. See the Addons page for details.

Where are my configs and addons stored?

Everything lives in a single Arsenic folder in your home directory: C:\Users\\Arsenic on Windows and ~/Arsenic on macOS and Linux. It is shared across Vanilla, Forge and Lunar.

How do I build Arsenic from source?

Install JDK 8 and set JAVA_HOME, clone the GitHub repository, run setup.bat (Windows) or setup.command (macOS/Linux), then open the generated Arsenic.ipr in IntelliJ. For setup help, contact @kv.dev on Discord.

Still stuck? Ask in the Discord or open an issue on GitHub.
